# Floppa disk
# Архитектура утилиты
Модули:

disk_info.asm — получение информации о дисках (размеры, типы, разделы).

partition_ops.asm — создание/удаление/изменение разделов.

fs_ops.asm — работа с файловыми системами (форматирование, метки).

main.asm — точка входа, CLI-интерфейс.

utils.asm — вспомогательные функции (вывод строк, конвертация чисел).
